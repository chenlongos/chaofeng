## 能力边界

当前已验证的是自然语言路由、端侧结构化计划、已知几何控制、有界会话上下文、离线预演和本机实时语音闭环。当前尚未完成真实视觉障碍物识别、未知环境自主导航、任意抽象轨迹、GPT 级开放指令理解，以及 310B 上可交付 OM / 板端 SenseVoice 推理。

涉及运动的系统坚持：大模型做高层语义和任务拆解；距离、角度、路径、安全边界和急停由确定性模块负责。
